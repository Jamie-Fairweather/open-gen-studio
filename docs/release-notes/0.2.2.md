# 0.2.2

**Released:** 2026-08-21

Store first-run now finishes ComfyUI install on clean Windows PCs. 0.2.1 often died during Python packages or extensions on certification VMs.

## Highlights

- First-run MSIX install completes on clean VMs that lack git and a machine-wide VC++ redistributable.
- Onboarding install errors stay on the overlay with Retry. The old "did not start" toast hid the real failure.

## Fixed

- **MSIX first-run install.** Portable Python now gets app-local VC++ DLLs next to `python.exe`. Clean Store VMs no longer fail with a missing `VCRUNTIME140.dll`. If `import torch` still hits WinError 126, the app tries a quiet VC redist install and reports it.
- **Long paths under MSIX.** pip was hitting Windows MAX_PATH under `Packages\…\LocalCache`. New installs default the library root to `%USERPROFILE%\Open Gen Studio`. An existing portable tree under Packages is moved to `%USERPROFILE%\.ogs\cui`, with a junction left at the old path.
- **Extensions without git.** Managed custom nodes download as pinned GitHub zips (`.oga_node_pin`). Git is only a fallback. A failed step hard-fails so Retry works, instead of pretending the install succeeded.
- **Onboarding kickoff race.** The Comfy install effect no longer re-runs mid-invoke and swallows the real error behind "did not start".
- **Hidden Store window.** Window-state no longer persists visibility, so a fresh Store install cannot restore a hidden window and look crashed (policy 10.1.2.10).
- **GPU VRAM on Hyper-V GPU-P.** Detection uses DXGI DedicatedVideoMemory when WMI AdapterRAM is empty.

## Added

- **Install Python packages** step in first-run progress (`ensurepip` / pip, after extract).
- In-overlay error alerts for GPU, storage, Hugging Face token, and install failures.

## Changed

- ComfyUI portable and managed nodes are pinned to ComfyUI v0.28.0. Those deps no longer track tip-of-tree.
- Onboarding overlay sits above toasts so install failures stay readable.

## Upgrade notes

- No migration required from **0.2.1** for unpackaged / NSIS installs.
- Store / MSIX users who already started a portable install under AppData Packages may see that runtime relocated to `%USERPROFILE%\.ogs\cui`. Gallery and models stay at the library root you picked. The new default is `%USERPROFILE%\Open Gen Studio`.
- Existing completed installs skip re-onboarding.
