# 0.2.1

**Released:** 2026-08-10

Patch release focused on first-run hardware gating and Microsoft Store packaging reliability.

## Highlights

- First-run onboarding now checks system RAM and VRAM against the product floor before install.
- MSIX Store packages include Official Blueprints and LoRAs again (empty catalogs blocked certification).

## Added

- **Hardware validation onboarding step** — detects system RAM + GPU VRAM via a new `get_system_specs` host command and shows a specs gate before storage/GPU setup.
  - Minimum: **16 GB RAM / 8 GB VRAM**
  - Recommended: **32 GB RAM / 16 GB VRAM**
  - Under-spec machines get a clear warning; users can still continue (bypass is remembered).
- Local MSIX sideload helper (`pack-local.ps1` / `desktop:pack:msix:local`) for self-signed install testing.

## Fixed

- **MSIX packaging missed `blueprints/` and `loras/`** — staging and pack scripts now copy those trees and refuse to pack if no `manifest.json` files are present (empty Official catalogs fail Store certification on first-run Blueprint picker).
- Blueprint/LoRA path resolution hardened for packaged installs.

## Changed

- Removed the GPU badge from the root README (platform badge remains Windows-focused).
- Partner Center / MSIX docs note honest system requirements aligned with the new onboarding floor.

## Upgrade notes

- No migration required from **0.2.0**.
- Existing installs skip re-onboarding unless onboarding state is reset; new installs see the Hardware step first.
- Store builders should use `bun run desktop:pack:msix` and confirm staged `blueprints/` + `loras/` before upload.
