# Catalog is what you have; Registry is how extras get in

PLAN used Registry for the Official/My picker and called an install a Preset. The shipping names are **Catalog** (one set of Blueprints, LoRAs, upscalers, Runtimes) and **Downloads** (the transfer queue). **Registry** is only the later public place to add extras.

A Catalog row is **Not installed** or **Installed** — not grouped by origin. Origin is a pill: **Official**, **Mine**, or **Registry**. Registry items get **Save to catalog** or **Save & install**. Preset, Projects, Resources, and Available are not product words.

We kept `recipe/`, `RecipeArch`, and `libraries/` as development names. Product copy does not say recipe.
