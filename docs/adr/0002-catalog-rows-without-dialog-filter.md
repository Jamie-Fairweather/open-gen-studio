# Runtime and Prompt Tools are Catalog rows, not dialog filters

Catalog is one set: Blueprints, LoRAs, upscalers, Prompt Tools, and Runtimes. Blueprint, LoRA, and upscaler pickers filter that set. Runtime and Prompt Tools stay Catalog rows in the host (Not installed / Installed) but are not shown as a filtered list — Runtime is supervised in Settings / First-run, Prompt Tools on the Tools screens.

We rejected putting them in the Catalog dialogs for consistency. The install path is the same module; the presentation stays where users already meet those rows.
